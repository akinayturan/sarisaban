# Sarışaban Hafızası

Chrysoupoli ve tarihî Sarışaban kazasının yer adları, mübadele izleri ve aile kayıtları için Türkçe Hugo arşivi.

## Yerel önizleme

Hugo 0.169.0 ile proje kökünde `hugo server --port 1314` çalıştırılır.

## Cloudflare Pages

Üretim dalı `main`. Framework preset `Hugo`, derleme komutu `hugo`, çıktı klasörü `public`. Üretim ve önizleme için `HUGO_VERSION=0.169.0`.

Kaynaklar ilgili içerikte ve kaynakçada gösterilir. İlk aile dizini, Cumhuriyet Arşivi tasfiye talepnamelerinin yayımlanan katalog özetlerine dayanır. Arşiv görselleri ve aile belgeleri kaynak ve kullanım izni bilgisiyle yayımlanır.
